# 保费业务口径示例

## 指标定义

- 保费：指订单中的 `insure_money` 字段，单位为元。
- 默认统计指标：`premium`，即订单保费的合计值。
- 默认统计表：`askdata_import.order_detail`。

## 时间口径

- 默认时间字段：`order_effective_time`，即订单生效时间。
- “去年”必须按系统当前日期的上一自然年解析，而不是数据库中最近有数据的年份。
- 如果目标时间范围内没有数据，应明确说明“该时间范围无数据”，不得回退到其他年份。

## 维度口径

- 省份：使用 `insure_unit_province`，显示值应包含行政区划后缀，例如“湖北省”。
- 产品线：标准指标维度为 `product_line`，对应物理表字段 `product_line_name`。
- 渠道：使用 `order_channel` 或标准指标中的 `order__channel_type`。
- 时间粒度：年份使用 `order_effective_year`，月份使用 `order_effective_month`。

## 常见回答要求

- 回答必须说明数据来源：dbt 标准指标或临时 SQL。
- 涉及金额时保留两位小数，并在必要时说明单位。
- 分组统计应说明分组维度和过滤条件。
